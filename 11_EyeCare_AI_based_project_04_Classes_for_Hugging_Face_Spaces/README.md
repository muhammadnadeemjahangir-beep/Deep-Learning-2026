# EyeCare AI - Eye Disease Detection System

## Overview

EyeCare AI is an AI-powered eye disease detection system developed using Deep Learning and YOLOv8.

The application analyzes eye images and detects possible eye diseases using a trained YOLO model.

## Features

- Upload eye images
- AI-based disease detection
- YOLOv8 object detection
- Confidence score display
- Detection result visualization

## Technologies Used

- Python
- YOLOv8 (Ultralytics)
- PyTorch
- OpenCV
- Gradio
- Hugging Face Spaces
