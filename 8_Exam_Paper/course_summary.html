2.1 The Perceptron (sklearn)

Dataset: placement.csv — 100 students, features: cgpa and resume_score, label: placed (0 or 1).

What a Perceptron is: The simplest neural unit. It takes inputs, multiplies each by a weight, sums them up, and applies a step activation function to produce a binary output.

Output = 1  if  (w1*cgpa + w2*resume_score + bias) >= 0
       = 0  otherwise

3.2 Solving Overfitting

Definition: Model memorizes training data instead of learning general patterns. High train accuracy, low val accuracy.
Analogy: A student who memorizes textbook answers but fails on new exam questions.

TechniquePurpose
Data AugmentationCreates varied versions of images so model can't memorize specific pixels
DropoutRandomly disables neurons during training — prevents co-adaptation
BatchNormalizationNormalizes layer outputs — stabilizes and speeds up training
L2 RegularizationPenalizes large weights — prevents overly complex learned functions
GlobalAveragePooling2DReplaces Flatten — reduces parameters, improves generalization
EarlyStoppingStops training when val_loss stops improving
ReduceLROnPlateauReduces learning rate when training gets stuck
ModelCheckpointSaves the best model based on val_accuracy

3.3 Solving Underfitting

Definition: Model fails to learn enough — performs poorly on BOTH train and validation data.
Analogy: A student who did not study at all — performs poorly everywhere.

Causes: Too much Dropout, too strong L2 regularization, too heavy data augmentation, not enough model capacity, learning rate too low or too high.

ProblemTrain AccVal AccMeaning
Underfitting55–65%54–63%Model too weak
Good fit85%82–85%Balanced
Overfitting97%+72–83%Model memorized data
Previous problemFix applied
Too much DropoutModerate Dropout (0.4)
Strong L2 (0.001)Light L2 (0.0001)
GlobalAveragePooling2DFlatten — gives Dense layer more information
Heavy augmentationModerate augmentation
Dense(128)Dense(256) — more learning capacity

Balanced CNN Code

    BatchNormalization(), MaxPooling2D(2,2),

    Conv2D(64, (3,3), activation="relu", padding="same"),
    BatchNormalization(), MaxPooling2D(2,2),

3.4 How CNN Layers Work

LayerWhat it does
Conv2DApplies learnable filters to extract features (edges, textures, shapes). Each filter produces a feature map.
MaxPooling2D(2,2)Reduces spatial dimensions by half — takes max value in each 2×2 window. Reduces computation, provides spatial invariance.
FlattenConverts 3D feature maps to 1D vector for Dense layers.
GlobalAveragePooling2DTakes average of entire feature map per channel — far fewer parameters than Flatten, better generalization.
DenseFully connected layer — every input connected to every output neuron.
Dropout(p)During training, randomly sets p fraction of neurons to 0 each batch.
BatchNormalizationNormalizes output of previous layer per mini-batch.
Output size formula
After Conv2D: (input_size - kernel_size + 1) without padding, or same size with padding="same".

4.1 What is Transfer Learning?

Definition: Taking a model trained on a large dataset (e.g., ImageNet with 1.2M images, 1000 classes) and reusing its learned weights for a new, related task.

Why it works
Lower layers of a CNN learn general features (edges, curves, textures) that are useful across many image tasks. Only higher layers learn task-specific features.
StrategyWhat you doWhen to use
Feature ExtractionFreeze all pre-trained layers, only train new top layersSmall dataset, similar domain
Fine-tuningUnfreeze last few layers + retrain with very small LRMedium dataset, want better performance
Exam note — key parameters
include_top=False — loads the pre-trained model WITHOUT its final 1000-class classifier. You add your own output layers on top.

base_model.trainable = False — freezes all pre-trained weights during initial training.

5.2 Keras Functional API

Why use it: The Sequential API only allows one input and one output, one path. The Functional API allows: multiple inputs, multiple outputs, shared layers, branching (skip connections like ResNet).

from keras.models import Model
from keras.layers import Input, Dense

x = Input(shape=(3,))                           # define input tensor
hidden1 = Dense(128, activation='relu')(x)      # call layer as function
hidden2 = Dense(64, activation='relu')(hidden1)

output1 = Dense(1, activation='linear')(hidden2)    # regression head
output2 = Dense(1, activation='sigmoid')(hidden2)   # classification head

model = Model(inputs=x, outputs=[output1, output2])
Key insight
Each layer is called as a function on a tensor, returning a new tensor. Model() just defines the computation graph.

Total params example: Input(3) → Dense(128) → Dense(64) → two Dense(1) = 8,898 params

6.2 Data Pipeline — tf.data (Modern Approach)

Why not ImageDataGenerator?
The old generator method causes a TypeError with dictionary-based multi-output models in newer TensorFlow. Use tf.data instead. 
def load_image_and_labels(filepath, age, gender):
    image = tf.io.read_file(filepath)
    image = tf.image.decode_jpeg(image, channels=3)
    image = tf.image.resize(image, (224, 224))
    image = preprocess_input(image)
    labels = {
        "age_output": tf.cast(age, tf.float32),
        "gender_output": tf.cast(gender, tf.float32)
    }
    return image, labels

dataset = tf.data.Dataset.from_tensor_slices((filepaths, ages, genders))
dataset = dataset.map(load_image_and_labels, num_parallel_calls=tf.data.AUTOTUNE)
dataset = dataset.batch(32).prefetch(tf.data.AUTOTUNE)

Compiling Multi-output Model

model.compile(
    optimizer=Adam(learning_rate=0.001),
    loss={
        "age_output": "mae",                   # Mean Absolute Error for regression
        "gender_output": "binary_crossentropy" # for classification
    },
    metrics={
        "age_output": ["mae"],
        "gender_output": ["accuracy"]
    },
    loss_weights={
        "age_output": 1.0,
        "gender_output": 5.0    # weight gender higher so it's not ignored
    }
)
Why loss_weights?
Age loss (in years) is numerically larger than binary crossentropy. Without weighting, gender learning gets ignored. Setting gender_output weight to 5.0 balances this.

6.4 Fine-tuning Process

# Phase 1: Freeze base model → train only top layers
model.fit(train_ds, epochs=10, ...)   # LR=0.001

# Phase 2 (Fine-tuning): Unfreeze last 30 layers → retrain with very small LR
base_model.trainable = True
for layer in base_model.layers[:-30]:
    layer.trainable = False           # still freeze earlier layers

model.compile(optimizer=Adam(learning_rate=1e-5), ...)  # very small LR
model.fit(train_ds, epochs=5, ...)
Why small LR for fine-tuning?
Pre-trained weights are already good — we want to gently adjust them, not destroy them with large updates.

7.1 Lab Task 1 — Image Basics and Preprocessing

Critical — BGR vs RGB
OpenCV reads images in BGR order (Blue-Green-Red), NOT the standard RGB. Matplotlib expects RGB. Always convert before displaying: 
img_bgr = cv2.imread("image.jpg")        # BGR
img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)   # convert for matplotlib
# Shape: (height, width, channels)
print(img.shape)    # e.g., (480, 640, 3)

# Grayscale conversion
gray = cv2.cvtColor(img_rgb, cv2.COLOR_RGB2GRAY)   # shape (H, W)

# Resize — NOTE: cv2.resize takes (width, height) — OPPOSITE of shape!
resized = cv2.resize(img_rgb, (300, 300))   # (width, height)

# Crop — numpy slicing: [rows(height), columns(width)]
cropped = img_rgb[y1:y2, x1:x2]

# Flip codes
cv2.flip(img, 1)   # 1 = horizontal flip (left-right)
cv2.flip(img, 0)   # 0 = vertical flip (up-down)
cv2.flip(img, -1)  # -1 = both axes

# Gaussian Blur — kernel must be ODD numbers
blurred = cv2.GaussianBlur(img, (9, 9), 0)

# Brightness & Contrast:  new_pixel = alpha * pixel + beta
result = cv2.convertScaleAbs(img, alpha=1.4, beta=40)
# alpha > 1 = more contrast, beta > 0 = brighter

# Save (convert back to BGR first)
cv2.imwrite("output.jpg", cv2.cvtColor(img_rgb, cv2.COLOR_RGB2BGR))
Exam — Lab Task 1 Questions
  1. What is the shape of your original image?
    img.shape returns (height, width, channels), e.g., (480, 640, 3)
  2. Why do we convert BGR to RGB?
    OpenCV reads images in BGR order; matplotlib and most display tools expect RGB. Displaying BGR as RGB swaps the red and blue channels, making the image look wrong.
  3. Why is resizing important before training a deep learning model?
    Neural networks require fixed input dimensions. All images in a dataset must be the same size (e.g., 150×150 or 224×224) so they can be batched together for training.
  4. Which preprocessing operation improved image quality the most?
    Brightness/contrast adjustment (convertScaleAbs) typically has the most visible effect on image quality.
  5. Why is preprocessing important in computer vision?
    Raw images have inconsistent sizes, lighting, and noise. Preprocessing standardizes them so the model learns features rather than irrelevant variations.

7.2 Lab Task 2 — Edge Detection and Contours

Original→ Grayscale→ Gaussian Blur→ Canny Edge Detection→ Contours→ Bounding Boxes 
# Canny Edge Detection
edges = cv2.Canny(blurred_gray, low_threshold=100, high_threshold=200)
# Two thresholds: strong edges (above high), weak edges (between), noise (below low)
# Weak edges kept only if connected to strong edges
# Output: binary image — white pixels = edges

# Find and draw contours
contours, hierarchy = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
cv2.drawContours(output_img, contours, -1, (255, 0, 0), 2)   # -1 = all contours

# Filter small contours (remove noise)
filtered = [cnt for cnt in contours if cv2.contourArea(cnt) > 100]

# Bounding boxes
for cnt in filtered_contours:
    x, y, w, h = cv2.boundingRect(cnt)
    cv2.rectangle(output, (x, y), (x+w, y+h), (255, 0, 0), 2)
Exam — Lab Task 2 Questions
  1. What is an edge in an image?
    A boundary where pixel intensity changes sharply — typically where one object ends and another begins (e.g., the outline of a coin on a table).
  2. Why do we apply blur before Canny edge detection?
    Canny detects intensity gradients. Noise creates many small gradients that produce false edges. Gaussian blur averages neighboring pixels, smoothing noise before the gradient is computed.
  3. How many objects/contours were detected?
    Depends on image. After filtering with area > 100, remaining contours represent real objects.
  4. What happens when you change low_threshold and high_threshold?
    Lower thresholds → more edges detected (including noise). Higher thresholds → fewer, stronger edges only. The ratio high:low = 2:1 or 3:1 is a good starting point.
  5. Mention two real-life applications of edge detection.
    Lane detection in self-driving cars; tumor boundary detection in medical imaging. (Also: document scanning, manufacturing defect detection, robotics object grasping.)

    cv2.rectangle(output, (x, y), (x+w, y+h), (255, 0, 0), 3)

scaleFactor1.05 → more detections, slower, more false positives1.3 → fewer detections, faster
minNeighbors2 → more detections, more false positives8+ → fewer false positives, may miss real faces

Haar Cascade limitations: Only detects frontal faces; fails in low light; produces false positives; cannot handle tilted/profile faces; cannot handle occlusion; slower and less accurate than modern DL detectors (MTCNN, RetinaFace).

8.1 YOLO — What It Is

YOLO = You Only Look Once
A real-time object detection algorithm that predicts bounding boxes and class labels in a single forward pass through the network.

Classification vs Detection
Classification: What is in the image? → one label
Detection: Where are the objects and what are they? → multiple bounding boxes + labels

def detect_image(image, confidence):
    if image is None:
        return None, "Please upload or capture an image first."

    image = image.convert("RGB")
    results = model.predict(source=image, conf=confidence, save=False)
    annotated_image = Image.fromarray(results[0].plot())   # draw boxes on image

    names = model.names
    detected = []
    if results[0].boxes is not None:
        for box in results[0].boxes:
            cls_id = int(box.cls[0])
            conf   = float(box.conf[0])
            detected.append(f"{names[cls_id]}: {conf:.2f}")

    summary = "No object detected." if not detected else "Detected objects:\n" + "\n".join(detected)
    return annotated_image, summary

10 · Quick-Reference Glossary

Perceptron
Simplest neural unit — weighted sum + step function. Can only solve linearly separable problems.
MLP
Multi-Layer Perceptron — multiple Dense layers. Can learn non-linear patterns.
ANN
Artificial Neural Network — general term for any network of neurons.
CNN
Convolutional Neural Network — uses Conv2D layers to extract spatial features from images.
Feature Map
Output of a convolutional filter applied to an input image.
Kernel/Filter
Small matrix of learnable weights in Conv2D (e.g., 3×3).
Stride
How many pixels the filter moves at each step.
Padding
Adding zeros around image to preserve spatial dimensions (padding="same").
MaxPooling
Downsampling operation. MaxPooling takes max in each 2×2 window.
Dropout
Regularization — randomly zeroes fraction of neurons per training step.
Batch Normalization
Normalizes layer activations per mini-batch — stabilizes and speeds training.
Overfitting
Model memorizes training data; poor generalization. Train acc >> Val acc.
Underfitting
Model too simple to learn. Both train and val acc are low.
Transfer Learning
Using weights pre-trained on a large dataset for a new task.
Fine-tuning
Unfreezing and retraining last layers of pre-trained model with small LR (1e-5).
ImageNet
1.2M image, 1000-class dataset used to pre-train most vision models.
GAP
GlobalAveragePooling2D — averages each feature map to one value. Reduces params.
Multi-output model
One model with multiple output heads (e.g., age + gender simultaneously).
MAE
Mean Absolute Error — average of |predicted - actual|. Used for regression.
Binary Crossentropy
Loss for 2-class problems with sigmoid output.
Softmax
Activation for multi-class output — outputs sum to 1.
Sigmoid
Activation for binary classification — outputs 0 to 1.
BGR
Blue-Green-Red — OpenCV's default channel order (opposite of standard RGB).
Canny
Edge detection algorithm using intensity gradient + two thresholds.
Contour
Continuous curve along the boundary of an object in an image.
Haar Cascade
Classical (non-DL) face detection using Haar-like features + AdaBoost.
YOLO
You Only Look Once — single-pass real-time object detection.
mAP
Mean Average Precision — standard detection evaluation metric.
IoU
Intersection over Union — measures overlap between predicted and actual bounding box.
Bounding Box
Rectangle (x, y, width, height) around a detected object.
Roboflow
Platform for dataset hosting, labeling, and export in YOLO/COCO formats.
Gradio
Python library for building quick ML demo web interfaces.
Hugging Face Spaces
Free hosting for ML demos (Gradio/Streamlit apps).
data.yaml
YOLO's dataset configuration file — class names, paths to train/val/test images.
best.pt
YOLO's saved model weights file from the best-performing training checkpoint.
tf.data
TensorFlow's high-performance data pipeline API. Replaces old ImageDataGenerator.
preprocess_input
Model-specific normalization function (different for ResNet50, MobileNetV2, etc.).
decode_predictions
Converts ImageNet model output probabilities to human-readable class names.
EarlyStopping
Stops training when a monitored metric stops improving (saves time, prevents overfit).
ReduceLROnPlateau
Reduces learning rate when training plateaus.
ModelCheckpoint
Saves model weights when monitored metric improves.
Confidence threshold
Minimum confidence score to count a detection as valid (e.g., 0.4 = 40%).
Precision
TP / (TP + FP) — of all positive predictions, how many were correct.
Recall
TP / (TP + FN) — of all actual positives, how many did model find.
F1 Score
Harmonic mean of Precision and Recall.
